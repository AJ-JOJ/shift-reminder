# 班表提醒

每天北京时间 **22:00**，自动读一次班表，如果**明天**有班，就往企业微信群里发一条提醒。

## 当前规则

- 只在**有班次的日期**提醒；空白 = 休息，**不提醒**
- `下大夜` 是大夜班的延续日，**不提醒**（配置在 `config.json` 的 `skip_shifts`）
- 其余班次（晚班、晚放、白班、大夜、备份、早放）都提醒

## 每月换班表（最重要，别忘了）

班表换月时，**代码一个字都不用改**，只要更新仓库根目录的 `banbiao.csv`。

**步骤**

1. 拿到新月份的班表
2. 新建内容 = **旧月份那几十行保留**，在最下面接着写新月份的（推荐合并，跨月不会断）
3. 打开仓库根目录的 `banbiao.csv` → 点铅笔图标 → 全选删掉 → 粘贴新内容 → Commit

**格式要求（必须保持）**

| 项目 | 要求 |
|---|---|
| 两列 | 第一列日期，第二列班次 |
| 表头 | `date,shift`（有没有表头都能认） |
| 日期格式 | `2026/11/1` 或 `2026-11-01`（**必须是真日期**，不能是 Excel 序列号） |
| 编码 | UTF-8 或 GBK 都行，程序会自动识别 |
| 文件名 | **保持 `banbiao.csv` 不变**（同名上传就是覆盖） |

**导出的正确做法**：Excel 里「另存为 → CSV」，不要手动复制粘贴（会被自动改格式）。

**忘了换会怎样**：程序查不到「明天」那一行 → 打印「跳过」→ **不发送，但也不报错**（静默失灵，所以务必月底前换好）。

**推荐做法**：文件名永远叫 `banbiao.csv`，但内容里**同时保留本月和次月**，这样即使某个月忘更新，也不会立刻断掉。

## 文件说明

| 文件 | 作用 |
|---|---|
| `main.py` | 入口：读班表 → 找到明天的班次 → 发送 |
| `schedule.py` | 读 CSV（日期 + 班次两列，自动识别 UTF-8 / GBK） |
| `notifier.py` | 往企业微信群机器人发消息 |
| `config.py` | 默认配置 + 读取 `.env` / 环境变量 |
| `config.json` | 要改行为时改这里（不含密码，可放心提交） |
| `.env` | **本地专用，含机器人地址，绝对不要提交** |
| `.github/workflows/remind.yml` | GitHub 上的定时规则 |

## 定时是怎么设的

on:
  schedule:
    - cron: "0 14 * * *"   # UTC 14:00 = 北京时间 22:00
